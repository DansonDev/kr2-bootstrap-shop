# Bootstrap Shop

Учебный многостраничный интернет-магазин на **Bootstrap 5.3.8**, выполненный в рамках дисциплины «Фронтенд и бэкенд разработка».

**Контрольная работа №2** — «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Проект представляет собой отдельную реализацию предметной области КР №1 с использованием Bootstrap: адаптивной сетки, готовых компонентов и utility-классов.

[Репозиторий для сдачи в СДО](https://github.com/DansonDev/kr2-bootstrap-shop)

## Страницы сайта

| Страница | Содержание |
| --- | --- |
| [Главная](index.html) | Шапка, навигация, hero-блок, преимущества, популярные товары и подвал |
| [Каталог](catalog.html) | Три карточки товаров с ценами и значками, модальное окно «Быстрая заявка» |
| [Товар](product.html) | Описание, цена, таблица характеристик, хлебные крошки и частые вопросы |
| [Заявка](order.html) | Форма с именем, e-mail, телефоном, выбором товара, комментарием и согласием на обработку данных |

На всех страницах используется единое меню с обозначением текущей страницы, выпадающим списком и раскрывающейся мобильной навигацией.

## Технологии и подключение Bootstrap

- **HTML5** — структура страниц и формы.
- **Bootstrap 5.3.8** — сетка, компоненты и utility-классы.
- **CSS3** — точечные настройки в `css/custom.css`.
- **Bootstrap JS Bundle** — мобильное меню, выпадающий список, модальное окно и Accordion.

Bootstrap подключён **через CDN jsDelivr** на всех четырёх страницах. Для загрузки CSS и JavaScript нужен доступ к интернету. Установка зависимостей и сборка не требуются.

В `<head>` сначала подключается Bootstrap CSS, затем собственные стили:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<link rel="stylesheet" href="css/custom.css">
```

Перед закрывающим тегом `</body>` подключается JS Bundle:

```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
```

## Реализованные компоненты

| Компонент | Где используется |
| --- | --- |
| `navbar`, `collapse`, `dropdown` | Основная навигация на всех страницах |
| `card` | Карточки каталога, блок изображения товара и форма заявки |
| `btn` | Переходы между страницами, открытие модального окна, отправка и сброс формы |
| `badge` | Метки «Новинка», «Хит» и «Скидка» |
| `alert` | Информационные сообщения в каталоге и форме, предупреждение на странице товара |
| `modal` | Быстрая заявка в каталоге |
| `form-control` | Поля ввода и комментарий |
| `form-select` | Выбор товара на странице заявки |
| `input-group` | Поле телефона с префиксом `+7` |
| `form-check` | Согласие на обработку данных в обеих формах |
| `accordion` | Раздел «Частые вопросы» на странице товара |
| `breadcrumb` | Хлебные крошки на странице товара |
| `table`, `table-responsive` | Таблица характеристик с прокруткой внутри блока при нехватке места |

## Сетка и оформление

Страницы построены на `container`, `container-fluid`, `row` и `col-*`. Отступы между колонками заданы через `g-3` и `g-4`.

| Ширина экрана | Популярные товары и каталог | Hero-блок |
| --- | --- | --- |
| Менее 768 px | 1 колонка | 1 колонка |
| От 768 до 991 px | 2 колонки | 1 колонка |
| От 992 px | 3 колонки | 2 колонки |

Меню сворачивается при ширине менее 992 px. Поля формы заявки размещаются в одну колонку на узких экранах и в две от 768 px; комментарий, согласие и кнопки занимают всю строку.

Файл `css/custom.css` задаёт минимальную высоту страницы и блоков-заглушек, а также стили для изображений карточек. Основное оформление выполнено классами Bootstrap.

## Локальный запуск

Откройте `index.html` в браузере. Также можно использовать Live Server в VS Code или запустить локальный сервер из папки проекта, если установлен Python 3:

```bash
python3 -m http.server 8000
```

После запуска перейдите на [localhost:8000](http://localhost:8000). Для остановки сервера нажмите `Ctrl+C` в терминале.

## Проверка проекта

1. Откройте все четыре страницы и проверьте ссылки основного и выпадающего меню.
2. В DevTools задайте ширины **375, 768, 1024 и 1440 px**. Проверьте перестроение колонок, раскрытие мобильного меню и отсутствие горизонтальной прокрутки страницы.
3. В каталоге нажмите «Заказать». Проверьте открытие модального окна и закрытие крестиком, кнопкой «Закрыть» и клавишей `Esc`.
4. На странице товара раскройте оба вопроса Accordion и проверьте таблицу характеристик.
5. На странице заявки попробуйте отправить пустую форму, затем введите некорректный e-mail. Браузер должен остановить отправку. Заполните поля и проверьте кнопку «Очистить».

## Особенности учебной версии

Товары и цены демонстрационные. Все ссылки «Подробнее» ведут на одну страницу товара; вместо изображений используются блоки-заглушки.

Backend и обработка заказов не подключены. На странице заявки используются встроенные проверки браузера: обязательные имя, e-mail и согласие, а также формат e-mail. Проверка формата телефона не реализована. Кнопка «Отправить» в модальном окне пока не имеет обработчика.
