# Bootstrap Shop

Учебный многостраничный интернет-магазин на **Bootstrap 5.3.8**, выполненный в рамках дисциплины «Фронтенд и бэкенд разработка».

**Контрольная работа №2** — «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Проект представляет собой отдельную реализацию предметной области КР №1 с использованием Bootstrap: адаптивной сетки, готовых компонентов и utility-классов. Дополнительно реализованы поиск, фильтрация каталога и проверка заявки на JavaScript.

[Репозиторий для сдачи в СДО](https://github.com/DansonDev/kr2-bootstrap-shop)

## Страницы сайта

| Страница | Содержание |
| --- | --- |
| [Главная](index.html) | Шапка, навигация, hero-блок, преимущества, популярные товары, раздел «Как оформить заявку» и подвал |
| [Каталог](catalog.html) | Три карточки, поиск, фильтр по цене, сортировка и модальное окно «Быстрая заявка» |
| [Товар](product.html) | Данные выбранного товара, таблица характеристик, хлебные крошки и частые вопросы |
| [Заявка](order.html) | Форма с именем, e-mail, телефоном, выбором товара, комментарием и согласием на обработку данных |

На всех страницах используется единое меню с обозначением текущей страницы, выпадающим списком и раскрывающейся мобильной навигацией.

## Технологии и подключение Bootstrap

- **HTML5** — структура страниц и формы.
- **Bootstrap 5.3.8** — сетка, компоненты и utility-классы.
- **CSS3** — точечные настройки в `css/custom.css`.
- **Bootstrap JS Bundle** — мобильное меню, выпадающий список, модальное окно, Accordion и Toast.
- **JavaScript** — поиск, фильтр, сортировка, выбор товара и обработка форм в `js/main.js`.

Bootstrap подключён **локально** на всех четырёх страницах. CSS и JS Bundle версии **5.3.8** находятся в `vendor/bootstrap/`. Проект работает без доступа к интернету; установка зависимостей и сборка не требуются.

Файлы взяты из [официального релиза Bootstrap 5.3.8](https://github.com/twbs/bootstrap/tree/v5.3.8/dist). MIT-лицензия сохранена в `vendor/bootstrap/LICENSE`.

В `<head>` сначала подключается Bootstrap CSS, затем собственные стили:

```html
<link href="vendor/bootstrap/css/bootstrap.min.css" rel="stylesheet">
<link rel="stylesheet" href="css/custom.css">
```

Перед закрывающим тегом `</body>` сначала подключается JS Bundle, затем собственный скрипт:

```html
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

| `navbar`, `collapse`, `dropdown` | Основная навигация на всех страницах |

## Сетка и оформление

Страницы построены на `container`, `container-fluid`, `row` и `col-*`. Отступы между колонками заданы через `g-3` и `g-4`.

| Ширина экрана | Популярные товары и каталог | Hero-блок |
| --- | --- | --- |
| Менее 768 px | 1 колонка | 1 колонка |
| От 768 до 991 px | 2 колонки | 1 колонка |
| От 992 px | 3 колонки | 2 колонки |

Меню сворачивается при ширине менее 992 px. Поля формы заявки размещаются в одну колонку на узких экранах и в две от 768 px; комментарий, согласие и кнопки занимают всю строку.

Файл `css/custom.css` задаёт размеры изображений, единые границы карточек и фильтра, состояние карточек при наведении и размеры уведомления. На телефоне кнопки переносятся, в модальном окне прокручивается содержимое. Основное оформление выполнено классами Bootstrap.

## Локальный запуск

Откройте `index.html` в браузере. Также можно использовать Live Server в VS Code или запустить локальный сервер из папки проекта, если установлен Python 3:

```bash
python3 -m http.server 8000
```

После запуска перейдите на [localhost:8000](http://localhost:8000). Для остановки сервера нажмите `Ctrl+C` в терминале.

## Самостоятельные доработки

Доработки выполнены сверх базовой структуры из методички, без дополнительных библиотек и сборщика.

| Доработка | Реализация |
| --- | --- |
| Локальный Bootstrap | CSS, JS Bundle и лицензия в `vendor/bootstrap/`; CDN не используется |
| Поиск и фильтр каталога | Поиск по названию, цена до 1500 руб. включительно или дороже 1500 руб., счётчик и сообщение для пустого результата |
| Сортировка | По возрастанию и убыванию цены; «Сбросить» возвращает исходный порядок и все товары |
| Выбор товара | Каждая карточка открывает данные своего товара через `?product=product-1`, `product-2` или `product-3`; выбранный товар передаётся в заявку |
| Проверка обеих форм | Обязательные поля, формат e-mail, телефон из 10 цифр после +7, запрет имени из пробелов; перезагрузки страницы нет |
| Дополнительный компонент Toast | После корректного заполнения появляется уведомление, которое можно закрыть |
| Новый раздел главной | «Как оформить заявку» объясняет последовательность действий |
| Изображения и оформление | Добавлено локальное учебное SVG, единое оформление карточек и фильтра, перенос кнопок на телефоне и прокрутка длинной формы в модальном окне |

## Проверка проекта

1. Откройте все четыре страницы и проверьте основное и выпадающее меню. Отключите интернет: оформление и интерактивные компоненты должны продолжать работать.
2. В DevTools задайте ширины **360, 375, 768, 1024 и 1440 px**. Проверьте перестроение колонок, мобильное меню и отсутствие горизонтальной прокрутки страницы.
3. В каталоге введите «Товар 2», затем несуществующее название. Проверьте счётчик и сообщение об отсутствии товаров. Совместите поиск с фильтром по цене.
4. Выберите сортировку «Сначала дороже»: порядок должен быть **Товар 3, Товар 2, Товар 1**. Кнопка «Сбросить» возвращает все три товара в исходном порядке.
5. Откройте «Подробнее» у каждого товара: название, цена и значок должны соответствовать карточке. Нажмите «Оформить заявку» и проверьте выбранный товар в форме.
6. В каталоге нажмите «Заказать» у второго или третьего товара. Проверьте подстановку товара, прокрутку формы и закрытие модального окна крестиком, кнопкой «Закрыть» и клавишей `Esc`.
7. В обеих формах проверьте пустые поля, неверный e-mail, короткий телефон и имя из пробелов. При корректных данных и согласии кнопка отправки показывает Toast, а поля очищаются. На странице заявки кнопка «Очистить» сохраняет товар, с которого открыли форму.
8. На странице товара раскройте оба вопроса Accordion и проверьте таблицу характеристик.

## Особенности учебной версии

Товары и цены демонстрационные. Для трёх товаров используется одна HTML-страница, которая выбирает данные по известному идентификатору из URL. При неизвестном идентификаторе отображается первый товар. Учебное SVG одинаковое для всех товаров.

Backend не подключён. Формы проверяют данные в браузере и показывают результат, но не отправляют и не сохраняют персональные данные. В Toast это указано явно. Корзина, оплата и личный кабинет не реализованы.
